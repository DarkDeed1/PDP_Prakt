# АС «Клиенты и сделки» для АО «Арвиай (Рашен Венчур Инвестментс)»

Веб-приложение на Django 4.2 для учета контрагентов, сделок, взаимодействий и пользовательских действий.

## Технологии
- Python 3.9+
- Django 4.2.x
- MySQL Server 8.0
- PyMySQL
- HTML + CSS без внешних UI-фреймворков

## Роли
- Администратор
- Менеджер
- Руководитель

## Демодоступ
- Администратор: admin / admin
- Менеджер: manager1 / manager1
- Менеджер: manager2 / manager2
- Руководитель: director / director

## Что входит
- dashboard с показателями и графическими блоками;
- учет контрагентов;
- учет сделок и история статусов;
- журнал взаимодействий;
- журнал действий пользователей;
- управление пользователями и ролями;
- фильтры во всех списках;
- demo SQL-дамп с предметными данными.
